# KUNA pitch video

Video je izrađen u Remotionu kao 16:9 prezentacijski materijal od 1 minute i 58 sekundi. Nakon uvoda prati stvarni tok KUNA aplikacije: odabir lokacije, slojeve karte, tržišni ritam, lokalni AI i plan pokretanja. Vizuali su namjerno čitljivi bez zvuka; tekst u `PITCH.md` služi kao govor prezentatora.

```bash
npm install
npm run studio
npm run render
```

Renderirana datoteka nastaje u `out/kuna-pitch.mp4`.
